# 三、对象数据规范
- 各对象采用**驼峰命名法**（统一为小写字符，单词之间使用下划线隔开），ODS层除外（与源系统保持一致）。  
- 命名优先级：英文简写 > 英文 > 中文拼音首字母，遵守“简短原则”，长度不超过30字符。  
- 业务相关命名需遵守现有词根。

| 计数相关 | xxx_cnt             | bigint  | 0          | 汇总字段需遵循“指标命名规范”                                         |
| 金额相关 | xxx_amt、xxx_price  | double  | 0          |                                                                      |
| 比率相关 | xxx_ratio           | double  | 0          |                                                                      |
| 描述相关 | xxx                 | string  | 空字符串   |                                                                      |
| 维度字段 | xxx                 | -       | -          | 取值必须与维度表保持一致                                             |
| 外键字段 | fk_xxx_id、fk_xxx_code、username | - | null | 关联时需注意数据倾斜                                                 |
| 是否字段 | is_xxx              | bigint  | -          | 0：否，1：是                                                         |
| 类型字段 | xxx_type、xxx_code  | string  | 非 null    | 编码/类型字段，取值需大写且遵守编码规范                              |

补充说明：
1. 建议在 app 层增加数据处理字段 `etl_time`；
2. 字段顺序需按业务相关性排序；
3. 维度字段不允许出现 `null` 或空字符串（''）。


## 3.3 指标规范
- 指标归属不同主题，分为**原子指标、派生指标、复合指标**三类。

### 3.3.1 时间修饰词
| 时间修饰词 | 英文简写 | 备注                     |
|------------|----------|--------------------------|
| 最近 N 天  | _nd      | 例：post_article_cnt_3d  |
| 最近 N 周  | _nw      |                          |
| 最近 N 月  | _nm      |                          |
| 最近 N 年  | _ny      |                          |
| 自然周     | _cw      |                          |
| 自然月     | _cm      |                          |
| 自然年     | _cy      |                          |
| 自然周至今 | _wtd     |                          |
| 自然月至今 | _mtd     |                          |
| 自然年至今 | _ytd     |                          |
| 历史至今   | _td      | to day（截至当天）       |


### 3.3.2 常用度量
| 度量       | 英文简写 | 类型    | 备注 |
|------------|----------|---------|------|
| 用户数量   | unt      | bigint  |      |
| 次数       | cnt      | bigint  |      |
| 数量       | num      | bigint  |      |
| 金额       | amt      | double  |      |
| 平均       | avg      | -       |      |
| 比率       | ratio    | double  |      |


### 3.3.2 指标命名
| 指标类型 | 名称规则                                   | 举例                     | 备注                                               |
|----------|--------------------------------------------|--------------------------|----------------------------------------------------|
| 原子指标 | {业务过程}_{度量方式}                      | 搜索次数：so_cnt         | 对应唯一业务过程，与度量方式一一对应               |
| 派生指标 | {原子指标}_{其他修饰词}_{时间修饰词}        | 最近一天搜索次数：so_cnt_1d | 由“原子指标 + 其他修饰词 + 时间修饰词”组成         |
| 复合指标 | {复合指标名称}（或采用相关简写）            | 转换率：xxx_up、ctr      | 由派生指标/其他复合指标经复杂运算获得，优先用简写 |


## 3.4 ETL命名规范
### 3.4.1 任务名称
为便于后续数据治理工具统一维护，需对ETL任务名称进行统一管理。

| 任务类型   | 子类型 | 名称规则                     | 举例                                               | 说明                               |
|------------|--------|------------------------------|----------------------------------------------------|------------------------------------|
| DLI 任务   | SQL    | {同表名一致}                 | 搜推搜索宽表任务：dwd_so_detail_di                 | 任务名称与对应表名完全相同         |
| DLI 任务   | Pipline| -                            | -                                                  | （无具体命名规则，待补充）         |
| CDM 任务   | 输入   | {同表名一致}_{数据源类型}cdm | -                                                  | 无需添加前缀                       |
| CDM 任务   | 输出   | out_{同表名一致}_{数据源类型}cdm | 将搜索宽表数据导出至 CK：out_dwd_sorev_so_topic_di_ckcdm | “out”表示输出任务，需指定数据源类型 |
| DLI 脚本   | -      | -                            | -                                                  | （无具体命名规则，待补充）         |
